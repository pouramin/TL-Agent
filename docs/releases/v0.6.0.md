# TL Studio v0.6.0

TL Studio 0.6 is a stable release focused on smarter native model routing, a cleaner plugin experience, Claude Web integration, and safer in-app updating.

## Native Agent and routing

- Keeps TL Studio in control of the Agent loop, tools, filesystem, permissions, sessions, retries, fallback, and Terminal.
- Strengthens project-relative path handling so routed Agents use the real workspace root instead of inventing paths.
- Uses a 4-minute routed-Agent model-turn timeout for heavier routed work while ordinary direct turns keep the 2-minute default.

## Laya Router

- Adds Laya as a global Plugin/MCP integration and a top-level model router.
- Adds Balanced, Lowest cost, Best quality, Fastest, and strict Free only profiles.
- Adds per-model enablement, cost group, quality, and speed controls in the responsive model-card UI.
- Keeps Free only strict: paid models are never used as fallback.

## JEV Direct

- Adds JEV Direct as a separate global router using TypeSafe System One directly with `jev-latest`.
- Validates the TypeSafe credential before enabling the router.
- Preserves the selected routing profile through fallback and removes paid candidates before JEV sees the pool in Free only mode.
- Keeps the existing **JEV via OpenRouter** integration intact and separate from **JEV Direct via TypeSafe**.

## Graphify and Plugins

- Installs Graphify once globally while keeping generated graph data project-local under `graphify-out/`.
- Graph creation is now explicit: a new project shows **Graph Missing** until **Build Graph** is selected.
- The default reliable build remains local and code-only with `graphify extract . --code-only`, followed by `graphify export html`.
- Exports both `graphify-out/graph.json` and the interactive `graphify-out/graph.html`.
- Migrates legacy project-scoped Graphify records without removing support for legitimate project-scoped custom MCP servers.
- Redesigns curated and added Plugins as responsive 3 / 2 / 1-column provider-style cards.

## Claude Web

- Supports the TL Studio Claude Web Bridge from the Chrome Web Store.
- Opens the installation page when the extension is missing, then automatically detects it after installation.
- Preserves automatic pairing repair and treats Claude Web readiness as part of routing/fallback eligibility.

## Providers

- Keeps account and API credential paths separate.
- Preserves the legacy JEV/OpenRouter provider while adding JEV Direct as a distinct router plugin.
- Improves provider/plugin card consistency and connection-state handling.

## Settings UX

- Uses a fixed 920×680 desktop Settings window that remains responsive on smaller viewports.
- Enforces one vertical scroll owner: `.settings-content`.
- Prevents the nested-scrollbar regressions previously seen in Providers and Plugins.

## Automatic updater

- Adds update checking in About using GitHub Releases.
- Stable builds ignore prereleases; prerelease builds may discover newer prereleases.
- On Windows x64, the updater downloads the official release archive and `SHA256SUMS.txt`, verifies SHA-256 before replacement, restarts TL Studio, and reopens the current project when possible.

## Reliability and fallback improvements

- Adds automatic rerouting for rate limits, unavailable models/providers, timeouts, empty responses, Claude Web readiness failures, and other transient route failures.
- Failed candidates can enter cooldown so repeated retries can move to another viable model.
- Routing/fallback activity remains visible in Chat.

Full release assets and checksums are attached to this GitHub Release.
