# TL Studio v0.6.1

TL Studio 0.6.1 is a focused patch release for the Native Agent runtime.

## Native Agent

- Raises the maximum Native Agent iterations from 24 to 128.
- Raises the maximum Tool rounds from 16 to 100.
- Keeps the per-round Tool-call limit at 16.
- Keeps repeated identical Tool-call protection at 4 attempts.

These limits give long-running coding and analysis tasks substantially more room to finish without weakening the existing repeated-call safety guard.

## Compatibility

This release otherwise keeps the TL Studio 0.6 stable architecture and provider/plugin behavior unchanged.
