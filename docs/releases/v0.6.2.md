# TL Studio v0.6.2

TL Studio 0.6.2 is a focused patch release for Native Agent model-request timeouts.

## Model request timeouts

- Raises the default direct model-turn timeout from 2 minutes to 4 minutes.
- Raises routed heavy/execution turns from 4 minutes to 6 minutes.
- Keeps the v0.6.1 Agent limits unchanged:
  - maximum iterations: 128
  - maximum Tool rounds: 100
  - maximum Tools per round: 16
  - repeated identical Tool-call guard: 4

This gives slower or heavier provider/model turns, including Mistral workloads, more time to finish before TL Studio aborts the request.

## Compatibility

This release otherwise keeps the TL Studio 0.6 stable architecture, provider behavior, Tool limits, and packaging unchanged.
