Kilo Local UI is a standalone, local browser interface for the Kilo Code agent runtime. It starts Kilo on your computer, puts a small authenticated Go proxy in front of it, and opens a browser UI — without requiring VS Code, JetBrains, Cursor, Docker, or a project-owned cloud service.

## What this project is

The project is deliberately a **thin product layer over Kilo**:

- **Kilo Code** remains responsible for sessions, agents, tools, filesystem access, provider integrations, and model execution.
- **Kilo Local UI** owns launch, local process lifecycle, browser UX, project selection, the local proxy boundary, and release packaging.

```text
Browser UI
    │
    │ localhost only
    ▼
Kilo Local UI launcher (Go)
    │
    │ authenticated reverse proxy
    ▼
kilo serve
    │
    ├─ sessions / agents / tools
    ├─ project files / terminal commands
    └─ configured AI providers
```

## Current capabilities

The current alpha can:

- run independently of an IDE;
- choose a local project directory;
- list and create Kilo sessions;
- send prompts and render user, assistant, reasoning, and tool activity;
- switch Kilo agents and models;
- use Kilo provider/device authorization flows;
- handle permission requests with `once`, `always`, or `reject`;
- handle questions raised by the agent;
- bundle the official pinned Kilo runtime in release packages;
- keep Kilo server credentials out of browser JavaScript.

## What you do not need

For a packaged release you do not need Node.js, npm, an IDE, Docker, a database, a VPS, or a separate Kilo installation. The downloadable archive includes the launcher and the pinned Kilo binary.
