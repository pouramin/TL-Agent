---
title: Launcher CLI
description: Reference the command-line options accepted by the Kilo Local UI launcher.
icon: Terminal
---

The launcher currently accepts these options.

## `--project`

Open a specific local directory as the initial project.

```bash
kilo-local-ui --project /path/to/project
```

A positional first argument is also accepted as the project path when `--project` is not supplied.

## `--kilo`

Use an explicit Kilo executable.

```bash
kilo-local-ui --kilo /path/to/kilo
```

## `--no-browser`

Start the local servers without opening the default browser automatically.

```bash
kilo-local-ui --no-browser
```

The launcher still prints the local URL so it can be opened manually.

## `--listen`

Choose the browser-facing listen address. The default is:

```text
127.0.0.1
```

Only loopback addresses are accepted. Attempts to bind the UI to a non-loopback interface fail intentionally.

## `KILO_BIN`

As an alternative to `--kilo`, set the Kilo executable through the environment:

```bash
KILO_BIN=/path/to/kilo kilo-local-ui
```
