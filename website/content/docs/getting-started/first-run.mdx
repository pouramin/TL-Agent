When you start Kilo Local UI, the launcher performs the runtime setup locally.

## Startup sequence

1. It resolves the project directory and Kilo executable.
2. It selects free loopback ports for the Kilo backend and browser UI.
3. It generates a fresh random Kilo server password for that run.
4. It starts `kilo serve` on `127.0.0.1`.
5. It waits for the backend to accept local connections.
6. It starts the browser-facing launcher server on loopback.
7. It opens the local UI in your default browser unless `--no-browser` was supplied.

The terminal prints the selected project, local browser URL, and backend URL.

## Choose a project

You can choose the project before launch:

```bash
kilo-local-ui --project /path/to/project
```

or select/change the local project from the UI. The launcher normalizes the selected path and only accepts an existing directory.

## Stop the app

Stopping the launcher also stops the Kilo child process. The launcher first requests a graceful stop and falls back to terminating the child if it does not exit in time.

## Important safety note

Kilo is a coding agent. Depending on the permissions you grant, it can read and modify project files and execute commands. Only open projects and machines you trust, and review permission requests before allowing sensitive actions.
