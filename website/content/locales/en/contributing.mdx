TL Agent application code and public documentation intentionally use separate build paths.

## Product development

The Go launcher lives under `cmd/launcher/`. Embedded browser assets live under `cmd/launcher/web/`. Internal engineering notes live under `docs/`.

## Public documentation

The public Fumadocs site lives under `website/` and has its own CI and GitHub Pages workflow.

```bash
cd website
npm install
npm run dev
```

Before proposing documentation changes:

```bash
npm run typecheck
npm run build
```

Keep user-facing wording centered on TL Agent. Runtime implementation details belong in the dedicated compatibility reference rather than product-facing pages.
