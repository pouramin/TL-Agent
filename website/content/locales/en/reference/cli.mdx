Most users can launch TL Studio from a Project directory and then use the graphical workspace.

## Project selection

```bash
tl-studio --project /path/to/project
```

Windows:

```powershell
tl-studio.exe --project "C:\path\to\project"
```

A positional Project path is also accepted:

```bash
tl-studio /path/to/project
```

## Do not open the Browser

```bash
tl-studio --no-browser
```

TL Studio still starts the local server and prints its `Local:` URL.

## Listen address

```bash
tl-studio --listen 127.0.0.1
```

The default is `127.0.0.1`.

TL Studio intentionally rejects non-loopback listen addresses.

## Removed legacy flags

v0.5 has no runtime-binary selection and no native-only switch. The product is already native, so those old compatibility-era launch options are not part of the current CLI.
