## Stable production

The `main` branch is the stable production line.

Stable quick launch:

~~~bash
npx --yes tl-studio
~~~

The npm package is a lightweight launcher pinned to the matching stable GitHub Release. It downloads the correct platform archive, verifies SHA-256, caches it locally, and runs TL Studio in the selected/current Project.

Stable npm publication uses non-prerelease versions from `main`.

## Development previews

The `dev` branch carries the next development line.

Preview Builds are produced separately for validation. They do not replace the stable npm launcher or stable GitHub Release.

The current development version is `v0.7.0-alpha.1`. Preview behavior must be labeled as development until promoted.

## Portable builds

Stable releases are produced for:

- Windows x64;
- Linux x64;
- Linux ARM64;
- macOS Intel x64;
- macOS Apple Silicon ARM64.

Each release publishes `SHA256SUMS.txt` alongside the platform archives.

## In-app updater

About can check GitHub Releases for updates.

- stable builds ignore prereleases;
- prerelease builds may discover newer prereleases;
- Windows x64 downloads the official archive and `SHA256SUMS.txt`;
- SHA-256 is verified before replacement;
- TL Studio restarts and attempts to reopen the current Project after a successful update.

## Release validation

Release and preview validation covers, as applicable:

- Browser TypeScript type-check and production build;
- Go tests and vet;
- supported platform cross-builds;
- Native Product Contract;
- Custom Provider Contract;
- Browser smoke testing;
- Agent/runtime E2E;
- provider/router/plugin regression tests;
- Windows review packaging;
- SHA-256 checksums for stable release artifacts.

Real user credentials are not used in CI.
