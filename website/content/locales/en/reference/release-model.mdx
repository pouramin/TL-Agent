Current stable release:

```text
v0.5.0
```

## Stable production

`main` is the stable production branch.

Stable quick launch:

```bash
npx --yes tl-studio
```

The npm package is a lightweight launcher pinned to the matching stable GitHub Release. It downloads the correct platform archive, verifies SHA-256, caches it locally, and runs TL Studio in the selected/current Project.

The stable npm workflow publishes only non-prerelease versions from `main` to the `latest` dist-tag.

## Portable builds

Stable Release builds are produced for:

- Windows x64;
- Linux x64;
- Linux ARM64;
- macOS Intel x64;
- macOS Apple Silicon ARM64.

A package contains the TL Studio executable, licenses/notices, and any version-pinned bundled Plugins configured for that release.


The current bundled Plugin manifest is empty, so no third-party bundled Plugin ships in v0.5.0.

## Release validation

The release pipeline:

- installs/builds Browser assets;
- type-checks Browser TypeScript;
- runs Go tests;
- cross-builds platform launchers;
- stages version-pinned bundled Plugins;
- runs a native Product Contract against the built TL Studio executable;
- produces SHA-256 checksums.

CI additionally covers Go vet, Browser JavaScript syntax, local Monaco assets, npm launcher validation, native Browser smoke, Provider contracts, Plugin staging, and regression tests.
