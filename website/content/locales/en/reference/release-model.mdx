## Stable production

The main branch is the stable production line.

Stable quick launch:

~~~bash
npx --yes tl-studio
~~~

The npm package is a lightweight launcher pinned to the matching stable GitHub Release. It downloads the correct platform archive, verifies SHA-256, caches it locally, and runs TL Studio in the selected/current Project.

The stable npm workflow publishes only non-prerelease versions from main to the latest dist-tag.

## Development previews

The dev branch carries the next-version development line.

Preview Builds are produced separately from stable releases and are intended for validation before promotion. They do not change the stable npm launcher or the stable GitHub Release.

The current v0.6.0-alpha.1 line includes work such as account-backed Provider integrations and native Gemini transport.

## Portable builds

Stable Release builds are produced for:

- Windows x64;
- Linux x64;
- Linux ARM64;
- macOS Intel x64;
- macOS Apple Silicon ARM64.

A package contains the TL Studio executable, licenses/notices, and any version-pinned bundled Plugins configured for that release.

## Release validation

Release and preview validation covers, as applicable:

- Browser TypeScript type-check;
- Browser production build;
- Go tests and vet;
- supported platform cross-builds;
- Native Product Contract;
- Custom Provider Contract;
- Browser smoke testing;
- Agent/runtime E2E;
- provider-specific regression tests;
- Windows review packaging;
- SHA-256 checksums for stable release artifacts.

Real user credentials are not used in CI.
