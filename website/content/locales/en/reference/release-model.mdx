TL Agent ships its own launcher/UI together with a pinned runtime so users can download one archive and run it directly.

## Stable and prerelease channels

**v0.2.0 is the first stable TL Agent baseline.** The npm package version is pinned to the matching GitHub Release, so the default command follows the stable `latest` channel:

```bash
npx --yes tl-agent
```

When prerelease builds are available, they use explicit dist-tags such as `alpha`:

```bash
npx --yes tl-agent@alpha
```

The npm package is only a lightweight launcher; it downloads and verifies the matching official release for the current platform.

## Portable release contents

A release archive contains:

- the TL Agent executable;
- the compatible bundled runtime;
- TL Agent licensing files;
- third-party notices and licenses.

The repository's `VERSION` tracks TL Agent. Runtime compatibility is pinned separately and validated by CI.

Release CI tests the product, resolves the exact compatible runtime, builds TL Agent for supported operating systems, packages the result, and publishes checksums.

Maintainers can see [Runtime integration](./runtime-integration) for the low-level compatibility contract.
