Current stable production:

```text
v0.5.0
```

At the time of this documentation refresh, `main` and `dev` point to the same validated v0.5.0 release commit.

There is therefore **no active next-version feature set to document yet**.

## Branch discipline

- `main` is stable production;
- `dev` is the integration line for the next development cycle;
- feature/fix branches start from `dev`;
- experimental work does not enter `main` until deliberate stable promotion.

## Private development builds

When `dev` advances again, experimental builds use GitHub Actions **Preview Build** artifacts rather than the stable npm `latest` channel.

The current Preview workflow produces a Windows x64 review ZIP and retains it for 14 days.

## Documentation rule

The public site documents stable behavior first.

A future development section should appear only after the repository contains real unreleased behavior. Version numbers and planned capabilities must not be invented in advance.
