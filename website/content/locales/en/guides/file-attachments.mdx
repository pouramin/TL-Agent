title: File attachments
description: Attach images, PDFs, and text/code files to prompts in TL Agent.

TL Agent can send local files with a prompt as structured file parts through the bundled runtime. You can attach working material without moving the project into a hosted TL Agent service.

## Ways to attach files

Use any of these from the composer:

- click the **+** attachment button and choose one or more files;
- drag files onto the composer;
- paste files from the clipboard into the prompt field.

Selected files appear as attachment chips before you send the prompt. You can remove individual files before sending.

## Supported file types

The current UI accepts:

- images: PNG, JPEG, WebP, and GIF;
- PDF documents;
- text and common code/config formats such as Markdown, JSON, YAML, TOML, CSV, JavaScript/TypeScript, Python, Go, Rust, Java, C/C++, CSS, HTML, SQL, shell scripts, patches, `.env`, and similar text files.

SVG files are treated as text rather than image input.

## Limits

TL Agent currently enforces these composer limits:

- up to **8 files** per prompt;
- up to **10 MB per file**;
- up to **20 MB total** across the pending attachments.

Unsupported binary formats are rejected before the prompt is sent.

## What happens when you send

The browser reads the selected file, creates a structured `file` prompt part, and sends it through TL Agent's local runtime API together with the text prompt. The user message then shows the attached filenames in conversation history.

Attachments are cleared after a successful send, when you start a new session, or when you switch projects. If sending fails before the runtime accepts the prompt, the pending attachments remain available so you can retry.

## Privacy and provider behavior

TL Agent does not upload attachments to a TL Agent-owned cloud backend. However, once you send the prompt, the attachment content can be forwarded by the local runtime to the model/provider you selected. Treat attachments with the same confidentiality rules as any other prompt content sent to that provider.
