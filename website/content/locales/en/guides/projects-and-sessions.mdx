## Local projects

TL Agent's project picker selects an existing directory on your computer. Project-scoped requests are routed locally so the active agent works inside that selected folder.

Changing projects changes the context used for sessions, messages, permissions, questions, events, and filesystem tools.

## Sessions

Sessions are shown and managed by TL Agent while the underlying runtime remains the source of execution state. You can create, rename, delete, reopen, and inspect sessions from the workspace.

## Messages and live activity

When you send a prompt, TL Agent follows session state and live events rather than treating the first HTTP response as the final answer. The interface can render assistant text, reasoning, tools, file activity, permissions, and questions as the run progresses.

Projected session messages remain the reconnect-safe source of conversation history.
