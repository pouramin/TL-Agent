title: Troubleshooting
description: Diagnose common TL Studio v0.5 startup, workspace, model connection, Plugin/MCP, Session, Permission, and Agent problems.

## Browser does not open

The local server may still be running. Open the `Local:` URL printed in the terminal manually.

If you used `--no-browser`, this is expected.

## Project picker rejects a folder

Choose an existing directory. TL Studio normalizes and validates the path before switching Project context.

## Monaco does not appear

TL Studio keeps a lightweight Editor fallback.

Official builds bundle Monaco and its workers locally, so no Editor CDN is required.

## A file will not save because it changed on disk

TL Studio detected that the disk revision changed after you opened the file.

Review the newer disk content. Use force-save only when you intentionally want the current buffer to replace it.

## Unsaved tabs block Project switching

Save the dirty tabs or explicitly discard them. TL Studio protects unsaved Editor work before switching Projects.

## Project Search misses a file

Search skips common heavy/generated directories, symlinks, binary/non-text content, and files larger than the native search limit.

Check Include/Exclude filters and Match Case too.

## A Terminal app needs a real TTY

The current Terminal is a command runner, not a full PTY terminal emulator.

Interactive TUI applications may not work correctly.

## Preview cannot open a file

Automatic file Preview is capability-driven. Current supported categories include HTML, SVG/raster images, PDF, supported video/audio, Markdown, and plain text/log files.

For a Node dev server, verify that `package.json` has a `dev` script and that the server prints a loopback URL.

## PDF Preview behaves differently across Browsers

TL Studio serves PDF inline with HTTP range support, but the embedded rendering is still the Browser's native PDF viewer.

Use **Open in Browser** if the embedded surface is limited.

## Model connection fails

Check:

- protocol;
- Base URL;
- API key;
- Model ID;
- whether the configured endpoint actually supports the selected protocol family.

Use **Test / Discover Models** to validate a connection that exposes model discovery.

## Model discovery fails

TL Studio blocks unsafe redirect behavior and treats authentication failures as real failures.

For a previously saved connection, a matching cached catalog may be used only for eligible non-auth live-discovery failures.

## An account-based Provider is not shown

That is expected in v0.5.0.

The generic Provider Account domain exists, but the current stable build registers no account adapter.

## Plugin is saved but does not run

Saving a Plugin intentionally leaves it disabled.

Enable it separately and confirm the local command before TL Studio starts the MCP process.

## Plugin Test Connection fails

Check the configured command, arguments, working directory, and required environment secrets.

The current Plugin architecture supports stdio MCP only. The MCP server must successfully initialize and expose `tools/list`.

## A Project-scoped Plugin appears under another saved Project

TL Studio can show saved Project Plugins from elsewhere so you can explicitly attach/move one to the current Project.

It does not silently run that Plugin against the wrong Project.

## Graphify cannot be enabled

The Graphify integration expects an existing graph before Graphify MCP queries are enabled.

Use **Build Graph / Rebuild Graph** if Graphify is installed and available in your environment.

Graphify is not bundled in v0.5.0.

## Agent is waiting

Check for a pending Permission request or interactive Question.

## “Always allow” is unavailable

Persistent approval is intentionally unavailable for sensitive execute/network requests and other requests that cannot be safely remembered.

## Session history remains after restart

This is expected. TL Studio owns local semantic Session persistence.

## Attachment is rejected

Current limits are **8 files**, **10 MiB per file**, and **20 MiB total**. Unsupported binary formats are rejected before send.

## Reporting a bug

Include your operating system, TL Studio version, reproduction steps, and non-secret error output.

For model-connection or Plugin problems, include the protocol/transport and non-secret configuration details. Never publish API keys or secret environment values.
