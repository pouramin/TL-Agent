## Start TL Studio

Run the portable executable, or start from a Project directory with:

~~~bash
npx --yes tl-studio
~~~

TL Studio starts its loopback local server and opens the Browser workspace.

## Choose a Project

Use the operating-system Folder Picker, or start the npm launcher from inside the Project directory so that folder is selected automatically.

You can also preselect a Project:

~~~bash
tl-studio --project /path/to/project
~~~

Windows:

~~~powershell
tl-studio.exe --project "C:\Users\you\Projects\my-project"
~~~

## Get oriented

The workspace is Editor-centered: Explorer, Search, Sessions, Changes, Settings, Monaco, the Agent panel, Terminal, Live Preview, Command Palette, and the Status Bar share one local workspace.

Open the Command Palette with Ctrl/Cmd+K. Project Search uses Ctrl/Cmd+Shift+F.

## Configure a model connection

Open **Settings → Providers**.

Stable v0.6 supports direct API/provider configuration plus supported account-backed paths:

- ChatGPT / Codex: official account sign-in;
- Claude / Anthropic: separate Claude account and API-key paths;
- Claude Web: Chrome Web Store bridge using the already signed-in Claude Web session;
- Google / Gemini: API-key preset;
- Hugging Face: API token;
- OpenRouter: API key.

Provider definitions and credentials remain separate.

## Optional model routing

The Model Selector can also use supported routers such as **Laya Router** or **JEV Direct**.

Available routing profiles include Balanced, Lowest cost, Best quality, Fastest, and strict Free only. The router chooses among enabled native models; TL Studio still owns the Agent loop, tools, permissions, sessions, retries, fallback, filesystem, and Terminal.

## Optional Plugins

Open **Settings → Plugins** to add MCP integrations.

Graphify is installed globally as an integration, but each Project keeps its own graph in `graphify-out/`. A new Project shows **Graph Missing** until you explicitly choose **Build Graph**.

## Run the Agent

Choose a configured Model or Router and send a prompt.

~~~text
Browser
→ TL Studio Session
→ Native Agent
→ Selected Provider / Router-selected native model
→ Tool Executor when needed
→ Session Persistence + Local Events
~~~

A Tool that needs approval pauses at TL Studio's Permission UI. The Agent can also ask a native interactive Question and resume after your answer.
