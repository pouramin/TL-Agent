## One-command launch

With Node.js/npm installed, run this inside the Project directory:

```bash
npx --yes tl-studio
```

The npm package is a lightweight launcher pinned to the matching stable GitHub Release. It detects the operating system and architecture, downloads the official archive, verifies its SHA-256 checksum, caches it locally, and starts TL Studio with the current directory selected.

Run without opening the Browser automatically:

```bash
npx --yes tl-studio --no-browser
```

## Portable release

Download the archive for your platform from GitHub Releases, extract it, and run:

```text
Windows:  tl-studio.exe
Linux:    ./tl-studio
macOS:    ./tl-studio
```

Stable builds are published for Windows x64, Linux x64/ARM64, and macOS Intel x64/Apple Silicon ARM64.

## What is inside v0.6.0?

A normal v0.6.0 package contains the TL Studio executable, required licenses/notices, configured bundled integration files, and the Claude Web Bridge integration files used by the supported Chrome extension workflow.

Graphify is installed as a reusable global integration when the user adds it; generated graph data stays project-local under `graphify-out/`.

## Verify a download

Each release publishes `SHA256SUMS.txt`. Compare the archive checksum with the published value if you want to verify the package.

The Windows x64 in-app updater performs the same SHA-256 verification before replacing the executable.

## Local cache used by the npm launcher

```text
Windows:     %LOCALAPPDATA%\TL-Studio\cache
Linux/macOS: ${XDG_CACHE_HOME:-~/.cache}/tl-studio
```

Nothing is installed as a system service or system package by the one-command launcher.
