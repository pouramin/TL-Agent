TL Studio is a **local-first coding workspace with a native Agent**. The workspace, sessions, tools, permissions, providers, credentials, Terminal, Preview, and Plugins/MCP all live behind TL Studio-owned local contracts.

This site distinguishes released behavior from development-preview behavior:

~~~text
Stable:      v0.5.0
Development: v0.6.0-alpha.1
~~~

## Product architecture

~~~text
You
 ↓
Browser Workspace
 ↓
TL Studio Local Core
 ├─ Files / Search / Terminal / Preview
 ├─ Provider Registry + Discovery + Credential Vault
 ├─ Sessions / Questions / Permissions / Events
 ├─ Tool Registry + Native Tool Executor
 ├─ Plugins / MCP
 └─ Native Agent
       ↓
   Selected Provider
~~~

Unsupported protocols or capabilities return an explicit unsupported-capability error.

## Stable v0.5

The stable release includes:

- the Editor-centered desktop workspace with Monaco, Explorer, Search, Sessions, Changes, Terminal, Preview, and Command Palette;
- native Sessions, Questions, Permissions, semantic Events, and local persistence;
- direct model execution through TL Studio-owned OpenAI-compatible, OpenAI Responses, and Anthropic protocol adapters;
- Provider model discovery, searchable catalogs, and local cache fallback;
- the TL Studio credential vault;
- the native model/tool/model Agent loop;
- built-in coding Tools plus compatible MCP tools;
- stable npm and portable release distribution.

## Development preview: v0.6

The current development line adds:

- native Google Gemini generateContent transport;
- separate manual-API and account credential slots;
- official account-backed connections for **OpenRouter**, **Hugging Face**, **Google / Gemini**, and **ChatGPT / Codex**;
- refresh/revocation support where the provider supports it;
- account-backed model discovery through the normal Provider Registry;
- in-app non-secret setup for Gemini's Google Cloud Project ID and Desktop OAuth Client ID;
- ChatGPT-plan login/model access through OpenAI's official Codex surfaces and an isolated provider bridge.

The following account integrations remain explicit deferred boundaries:

- Claude consumer account login;
- GitHub Copilot.

The ChatGPT bridge does not replace TL Studio's outer Native Agent loop: TL Studio still owns Tools, Permissions, Sessions, persistence, and project mutations.

## Quick start

Stable launch:

~~~bash
npx --yes tl-studio
~~~

Or download a portable build from GitHub Releases.
