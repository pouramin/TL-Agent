TL Studio is a **local-first browser IDE and coding-agent workspace**. Stable v0.5 is one TL Studio application: workspace, Monaco Editor, Search, Terminal, Preview, Sessions, Questions, Permissions, Providers, Plugins/MCP, and the Native Agent all run behind TL Studio-owned local contracts.

## Product architecture

```text
You
 ↓
Browser Workspace
 ↓
TL Studio Local Core
 ├─ Files / Search / Terminal / Preview
 ├─ Provider Registry + Discovery + Credential Vault
 ├─ Sessions / Questions / Permissions / Events
 ├─ Tool Registry + Native Tool Executor
 ├─ Plugins / MCP
 └─ Native Agent
       ↓
   Selected Provider
```

If a selected protocol or capability is unsupported by TL Studio's native model client, the run fails explicitly.

## What v0.5 includes

- an Editor-centered desktop workspace with Activity Rail, Context Sidebar, Monaco, Agent panel, Terminal, floating Preview, and Status Bar;
- a Command Palette on `Ctrl/Cmd+K`;
- resizable/persisted workspace panels and Collapsed, Compact, and Focused Agent presentation modes;
- writable Project files with revision/conflict protection and external-change reconciliation;
- Project Search and project-scoped process execution;
- capability-driven Preview for web, documents, images, audio, and video;
- fully native Session lifecycle and local semantic persistence;
- fully native interactive Questions and Permission policy;
- direct model execution through TL Studio-owned native protocol adapters;
- Provider model discovery with searchable catalogs and local cache fallback;
- secure local Provider credentials;
- a native model/tool/model Agent loop;
- core coding Tools plus dynamic tools from compatible MCP plugins;
- project/global stdio MCP configuration with explicit enable/test flows;
