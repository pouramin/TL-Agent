TL Studio is a standalone local development environment built around the **TL Studio Native Agent**.

Current channels:

~~~text
Stable:      v0.6.0
Development: v0.7.0-alpha.1
~~~

## Stable v0.6.0

The current stable release includes:

- the TL Studio-owned Agent loop, Tool Executor, Sessions, Questions, Permissions, Terminal, Preview, and persistence;
- direct model protocols for OpenAI-compatible Chat Completions, OpenAI Responses, Anthropic Messages, and Google Gemini `generateContent`;
- ChatGPT/Codex account access and Claude account access through the providers' official client surfaces;
- Claude Web Bridge support through the Chrome Web Store while the authenticated browser session remains browser-owned;
- Laya Router and JEV Direct as model-selection routers with Balanced, Lowest cost, Best quality, Fastest, and strict Free only profiles;
- Graphify as a global integration with project-local graph output under `graphify-out/`;
- responsive provider-style Plugin cards and preserved support for custom project-scoped MCP servers;
- automatic update checks in About, with SHA-256 verification before Windows x64 replacement.

Routing plugins choose a native model only. TL Studio still owns tools, filesystem access, permissions, sessions, retries, fallback, Terminal, and every model → Tool → model continuation.

## Quick start

Run the stable release from a Project directory:

~~~bash
npx --yes tl-studio
~~~

Portable archives are also available from GitHub Releases.
