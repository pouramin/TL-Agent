TL Agent is a **local, standalone coding-agent workspace**. It gives you a dedicated browser environment for working with local projects, sessions, agents, models, tools, permissions, file changes, and project files without requiring an IDE.

## Product identity

TL Agent is the product you install and interact with. Kilo Code is an upstream runtime dependency used underneath TL Agent for agent execution, tools, sessions, and provider integrations.

```text
You
  ↓
TL Agent
  ├─ browser workspace
  ├─ project picker
  ├─ sessions and changes
  ├─ local security boundary
  └─ launcher + packaging
       ↓
Agent runtime (Kilo)
       ↓
Models / providers / project tools
```

This separation is intentional: normal TL Agent usage should feel like using TL Agent, not like operating a Kilo command-line wrapper.

## What you can do

- choose a local project from the operating-system folder picker;
- create, rename, and delete sessions;
- choose an agent and available model;
- send prompts and follow live reasoning/tool activity;
- approve or reject permission requests;
- answer interactive questions from the agent;
- inspect project files and file changes;
- interrupt an active run;
- use the application without VS Code, JetBrains, Cursor, Docker, or a TL Agent cloud backend.
