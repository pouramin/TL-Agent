Project Search مستقیماً توسط TL Studio اجرا می‌شود و به External Search Binary یا Agent Tool Call نیاز ندارد.

از Activity Rail آن را باز کنید یا از این Shortcut استفاده کنید:

```text
Ctrl/Cmd + Shift + F
```

## Search Controlها

Search از این موارد پشتیبانی می‌کند:

- Literal Text Search؛
- Case-sensitive Matching؛
- Include Pattern؛
- Exclude Pattern؛
- رفتن مستقیم به File، Line و Column دقیق.

اگر Query جدیدی جای Query قبلی بیاید، UI Search قدیمی در حال اجرا را Cancel می‌کند.

## Limitهای فعلی

Limitهای Native فعلی:

- Maximum Query برابر **512 bytes**؛
- Maximum File قابل Scan برابر **2 MiB**؛
- Maximum Result برابر **500 Match**؛
- Snippet تا **240 Rune**.

Directoryهای سنگین/Generated زیر به‌صورت پیش‌فرض Ignore می‌شوند:

```text
.git
node_modules
dist
build
out
coverage
.next
```

Symlink و Fileهایی که Text عادی قابل Search نیستند مثل Project Content معمولی Traverse نمی‌شوند.

## Include و Exclude

برای Project بزرگ از Include/Exclude استفاده کنید. Exclude برای Folderهای Generated مخصوص Stack هم مفید است.

Project Search فقط Read است و **Replace in Files در v0.6 پیاده‌سازی نشده است.**
