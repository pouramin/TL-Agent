در Stable v0.6 یک **Plugin/MCP System متعلق به خود TL Studio** وجود دارد. MCP Server فعال می‌تواند Toolهای خودش را وارد همان Tool Registry و Native Agent کند که Built-in Toolهای کدنویسی استفاده می‌کنند.

## پشتیبانی MCP فعلی

```text
Type:      MCP
Transport: stdio
Scope:     project or global
```

پشتیبانی از MCP سفارشی Project-scoped همچنان حفظ شده است.

صرف Save کردن Plugin هیچ Commandی را Start نمی‌کند. Enable یک Action جدا و صریح است و قبل از Start شدن Command محلی، TL Studio تأیید می‌گیرد.

## رابط Plugin

Pluginها در کارت‌های شبیه Provider داخل این بخش‌ها نمایش داده می‌شوند:

- Available integrations؛
- Included with TL Studio؛
- Added by you.

Grid به‌صورت Responsive در Desktop عریض 3 ستون، در اندازهٔ متوسط 2 ستون و در عرض کم 1 ستون دارد.

## Graphify

Graphify فقط یک‌بار به‌صورت Global نصب می‌شود، اما دادهٔ Graph هر Project محلی باقی می‌ماند.

Project بدون Graph وضعیت **Graph Missing** نشان می‌دهد. ساخت Graph فقط با Action صریح **Build Graph** انجام می‌شود و Add کردن Graphify باعث Build خودکار نمی‌شود.

Build محلی قابل اتکا:

~~~bash
graphify extract . --code-only
graphify export html
~~~

خروجی‌ها:

~~~text
graphify-out/graph.json
graphify-out/graph.html
~~~

هنگام تغییر Project، MCP Process سراسری با Working Directory مربوط به Project فعال Restart می‌شود.

## Router Plugin

Router Plugin از MCP Tool Plugin جداست. روی انتخاب Model اثر می‌گذارد، اما وارد Tool Registry نمی‌شود.

### Laya Router

Laya به‌صورت Plugin/MCP سراسری نصب می‌شود و در عین حال می‌تواند به‌عنوان Model Router سطح بالا در Model Selector دیده شود.

### JEV Direct

JEV Direct یک Router سراسری و جداست که مستقیم TypeSafe System One را با `jev-latest` صدا می‌زند.

هر دو Router فقط Model بومی انتخاب‌شده را به TL Studio برمی‌گردانند. Tool، Permission، File، Session، Terminal، Retry و Agent Loop در اختیار خود TL Studio می‌مانند.

## Secret و Permission

Plugin Secret از Credential Vault خود TL Studio استفاده می‌کند.

MCP Tool کشف‌شده قبل از اجرای واقعی همچنان از Permission Authorizer خود TL Studio عبور می‌کند.
