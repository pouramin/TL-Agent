Coding Agent ممکن است قبل از انجام یک عملیات حساس نیاز به اجازه داشته باشد یا برای ادامه کار از شما سؤال بپرسد.

## پاسخ به Permission

TL Agent در حال حاضر سه گزینه نشان می‌دهد:

- `once` — فقط همین بار اجازه بده؛
- `always` — طبق رفتار Runtime، Rule مربوط را ذخیره و اجازه بده؛
- `reject` — درخواست را رد کن.

قبل از اجازه دادن به اجرای Command یا تغییر فایل، درخواست را بخوانید.

## سؤال‌ها

Questionهای تعاملی را می‌توانید مستقیم داخل TL Agent پاسخ دهید؛ از انتخاب یک گزینه تا چند گزینه یا پاسخ سفارشی.

اجرای محلی سطح شبکه را محدود می‌کند، اما امنیت نهایی همچنان به Permissionهایی بستگی دارد که به Agent می‌دهید.
