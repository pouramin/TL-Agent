Agent Composer، Local File را به‌عنوان Structured Prompt Part می‌پذیرد.

## روش‌های Attach

- دکمه **+**؛
- Multi-select؛
- Drag & Drop؛
- Paste از Clipboard.

Attachment قبل از Send به‌شکل Chip دیده می‌شود و قابل حذف است.

## Formatهای UI

Composer فعلی این موارد را می‌پذیرد:

- Imageهای PNG، JPEG، WebP و GIF؛
- PDF؛
- Text و Code/Config Fileهای رایج.

SVG به‌عنوان Text Input Normalize می‌شود، نه Image Input.

## Limitها

Limit فعلی سمت Client:

- **8 فایل** در هر Prompt؛
- **10 MiB برای هر File**؛
- **20 MiB مجموع** Attachmentهای Pending.

Binary Format پشتیبانی‌نشده قبل از Send Reject می‌شود.

## رفتار Native Session

Attachment از Native Session Run Contract خود TL Studio عبور می‌کند.

Metadata مربوط به Attachment ارسال‌شده می‌تواند کنار User Message در Semantic Session History باقی بماند. Payload Inline با Prefix `data:` قبل از Persist شدن Session Snapshot حذف می‌شود.

بعد از Send موفق، New Session یا Project Switch، Attachment Pending پاک می‌شود. اگر Send قبل از Accept شدن Fail شود، File می‌تواند برای Retry باقی بماند.

## Provider Capability

اینکه Composer یک File را Accept می‌کند به معنی پشتیبانی تمام Provider/Modelها از همان Binary Format نیست.

Multimodal Behavior به Native Provider Protocol و Model انتخاب‌شده بستگی دارد.

## Privacy

TL Studio Attachment را به Cloud Backend متعلق به خودش Upload نمی‌کند.

محتوایی که برای Model Request لازم است می‌تواند مستقیم به Provider Endpoint انتخاب‌شده توسط User ارسال شود.
