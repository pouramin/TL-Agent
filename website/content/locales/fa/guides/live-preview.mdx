TL Studio از Preview مبتنی بر Capability استفاده می‌کند و Preview فقط به Root `index.html` محدود نیست.

## File Typeهای قابل Preview

Capability Registry فعلی این موارد را می‌شناسد:

- HTML؛
- SVG و Raster Image؛
- PDF؛
- Video؛
- Audio؛
- Markdown رندرشده؛
- Plain Text/Log رندرشده.

نمونه‌های پشتیبانی‌شده شامل PNG/JPEG/WebP/GIF/AVIF/BMP/APNG، MP4/WebM، MP3/WAV/OGG/M4A/AAC/FLAC و Fileهای استاندارد PDF/Markdown/Text هستند.

Binary/Media File قابل Preview می‌تواند به‌عنوان Tab واقعی و Read-only در Workspace باز شود.

## Preview مربوط به File فعال

Floating Preview می‌تواند File قابل Preview فعال در Editor Workspace را دنبال کند.

اگر File مشخصی انتخاب نشده باشد، TL Studio می‌تواند Root `index.html`، یک File Previewable دیگر یا Node Dev Server پشتیبانی‌شده را انتخاب کند.

## Node Development Server

اگر `package.json` دارای Script به اسم `dev` باشد، TL Studio می‌تواند این Command را با Native Process Manager اجرا کند:

```text
npm run dev
```

و Loopback URL اعلام‌شده توسط Server را پیدا کند.

فقط Local Preview URL پذیرفته می‌شود.

## PDF

PDF با MIME/Disposition مناسب و HTTP Range Support به‌صورت Inline Serve می‌شود تا PDF Viewer خود Browser بتواند داخل File Seek کند.

## Floating Window

Live Preview Drag و Resize از هر 4 لبه و هر 4 گوشه را پشتیبانی می‌کند.

Geometry به‌صورت Local زیر این Key ذخیره می‌شود:

```text
tl-studio.preview-window
```

اگر Viewport عوض شود، Geometry ذخیره‌شده به محدوده قابل‌استفاده Clamp می‌شود.

## Security Boundary

Project Code داخل Preview با Privileged Control Origin مربوط به TL Studio مشترک نیست.

Static/File Preview روی Loopback Origin جدا اجرا می‌شود و Node Preview فقط Loopback URL را می‌پذیرد.

Preview File Server فقط Read است و Path Traversal/Symlink Escape Protection همچنان اعمال می‌شود.
