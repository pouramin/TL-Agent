## پروژه محلی

Folder Picker در TL Agent یک پوشه موجود روی کامپیوتر شما را انتخاب می‌کند. درخواست‌های مربوط به پروژه به‌صورت محلی Route می‌شوند تا Agent داخل همان پوشه کار کند.

با تغییر پروژه، Context مربوط به Sessionها، Messageها، Permissionها، Questionها، Eventها و ابزارهای فایل هم تغییر می‌کند.

## Sessionها

TL Agent Sessionها را در Workspace نمایش می‌دهد و مدیریت می‌کند. می‌توانید Session جدید بسازید، نامش را تغییر دهید، حذفش کنید یا دوباره بازش کنید.

## Message و فعالیت زنده

بعد از ارسال Prompt، TL Agent وضعیت Session و Eventهای زنده را دنبال می‌کند و Text، Reasoning، Toolها، تغییر فایل، Permission و Question را هنگام اجرا نشان می‌دهد.
