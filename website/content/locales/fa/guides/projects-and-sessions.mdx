## Project محلی

Folder Picker در TL Agent یک Folder موجود روی کامپیوتر شما را انتخاب می‌کند. Requestهای مربوط به Project به‌صورت Local Route می‌شوند تا Agent داخل همان Folder کار کند.

با تغییر Project، Context مربوط به Sessionها، Messageها، Permissionها، Questionها، Eventها و File Toolها هم تغییر می‌کند. Attachmentهای Pending در Composer هم هنگام تغییر Project پاک می‌شوند تا ناخواسته وارد Context پروژه دیگری نشوند.

## Sessionها

TL Agent Sessionها را در Workspace نمایش می‌دهد و مدیریت می‌کند. می‌توانید Session جدید بسازید، Rename کنید، حذف کنید یا دوباره بازش کنید.

با ساخت Session جدید، Attachmentهای ارسال‌نشده Composer پاک می‌شوند. فایل‌هایی که قبلاً Send شده‌اند همچنان روی User Message مربوط در Conversation History دیده می‌شوند.

## Message و Live Activity

بعد از ارسال Prompt، TL Agent وضعیت Session و Eventهای Live را دنبال می‌کند و Text، Reasoning، Toolها، File Activity، Permission، Question و Filenameهای Attach‌شده را هنگام اجرا نشان می‌دهد.

## Usage Summary

هرجا Runtime اطلاعات Usage را در اختیار TL Agent بگذارد، UI می‌تواند مصرف هر Turn و مجموع Project را برای Token/Request، Time، Reasoning و Cache نشان دهد. این اطلاعات بخشی از Local Workspace هستند و به Telemetry Backend متعلق به TL Agent ارسال نمی‌شوند.
