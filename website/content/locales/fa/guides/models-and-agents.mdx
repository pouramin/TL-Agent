TL Agent، Agentها، Providerها و Modelهایی را نشان می‌دهد که Runtime Local در اختیارش می‌گذارد. TL Agent Model Router یا Model Inference Backend جداگانه‌ای روی آن نمی‌سازد.

## Agentها

مسیر اصلی Coding از Agent محصولی `code` استفاده می‌کند. انتخاب Agent داخل TL Agent انجام می‌شود و اجرای واقعی در Runtime زیرین صورت می‌گیرد.

## Model و Provider

Model می‌تواند از Kilo-hosted Providerها بیاید یا از Custom Endpoint سازگاری که در **Settings → Providers** اضافه کرده‌اید. TL Agent هنگام شروع کار Provider/Model انتخاب‌شده را به Runtime Local می‌فرستد.

برای API Familyهای پشتیبانی‌شده و نحوه ذخیره Config و API Key، [Custom Providerها](./custom-providers) را ببینید.

## Kilo Account Login

برای Modelهای Hosted در Kilo، TL Agent همان Device Authorization خود Kilo را نمایش می‌دهد. Credentialها و Model Inference از Cloud متعلق به TL Agent عبور نمی‌کنند.

## Provider Error

حتی وقتی TL Agent و Runtime Local سالم هستند ممکن است Provider موقتاً Error بدهد. اگر Runtime بعد از Retry Cycle به یک Retryable Provider Error برسد، TL Agent می‌تواند دکمه **Resume** نشان دهد تا کار از Workspace State فعلی ادامه پیدا کند و لازم نباشد از اول شروع کنید.
