## Stable Production

Branch `main` خط Stable Production است.

اجرای سریع:

```bash
npx --yes tl-studio
```

پکیج npm یک Launcher سبک و Pin‌شده به GitHub Release متناظر است. Archive درست را برای Platform دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را داخل Project انتخاب‌شده/فعلی اجرا می‌کند.

Stable npm Workflow فقط Version غیرPrerelease را از `main` روی Dist-tag به نام `latest` Publish می‌کند.

## Portable Build

Stable Release برای این Platformها ساخته می‌شود:

- Windows x64؛
- Linux x64؛
- Linux ARM64؛
- macOS Intel x64؛
- macOS Apple Silicon ARM64.

Package شامل Executable خود TL Studio، License/Noticeها و Bundled Plugin نسخه‌ثابت Configure‌شده برای همان Release است.

v0.5.0 **Coding Runtime Binary جداگانه‌ای ندارد.**

Bundled Plugin Manifest فعلی خالی است و Third-party Bundled Plugin داخل v0.5.0 توزیع نمی‌شود.

## Release Validation

Release Pipeline:

- Browser Asset را Install/Build می‌کند؛
- Browser TypeScript را Type-check می‌کند؛
- Go Test اجرا می‌کند؛
- Launcher مربوط به Platformها را Build می‌کند؛
- Bundled Plugin نسخه‌ثابت را Stage می‌کند؛
- بررسی می‌کند Sidecar Binary منسوخ وارد Package نشده باشد؛
- Native Product Contract را روی Executable ساخته‌شده اجرا می‌کند؛
- SHA-256 Checksum تولید می‌کند.

CI همچنین Go Vet، Browser JavaScript Syntax، Local Monaco Asset، npm Launcher، Native Browser Smoke، Provider Contract، Plugin Staging و Regression Testها را پوشش می‌دهد.

## Preview Build

Development روی `dev` می‌تواند GitHub Actions Preview Build خصوصی تولید کند.

Workflow فعلی Windows x64 می‌سازد و Artifact را 14 روز نگه می‌دارد.

Preview Build تا زمان Promotion، Stable npm `latest` یا Stable GitHub Release را تغییر نمی‌دهد.
