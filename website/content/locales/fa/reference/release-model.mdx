کانال‌های فعلی انتشار:

~~~text
Stable:      v0.6.0
Development: v0.7.0-alpha.1
~~~

## نسخهٔ پایدار

شاخهٔ `main` خط Stable Production است.

اجرای سریع نسخهٔ پایدار:

~~~bash
npx --yes tl-studio
~~~

پکیج npm یک Launcher سبک و متصل به GitHub Release پایدار متناظر است. Archive مناسب Platform را دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را داخل Project انتخاب‌شده یا فعلی اجرا می‌کند.

انتشار پایدار npm فقط برای Version غیرPrerelease روی `main` انجام می‌شود.

## Development Preview

شاخهٔ `dev` خط توسعهٔ نسخهٔ بعدی است.

Preview Buildها جدا از Stable Release ساخته می‌شوند و برای Validation قبل از Promotion هستند. این Buildها Stable npm یا Stable GitHub Release را جایگزین نمی‌کنند.

نسخهٔ فعلی Development برابر `v0.7.0-alpha.1` است و قابلیت‌های آن تا زمان Promotion باید Development محسوب شوند.

## Portable Build

Stable Release برای این Platformها ساخته می‌شود:

- Windows x64؛
- Linux x64؛
- Linux ARM64؛
- macOS Intel x64؛
- macOS Apple Silicon ARM64.

کنار Archiveهای Platform، فایل `SHA256SUMS.txt` هم منتشر می‌شود.

## Updater داخلی

بخش About می‌تواند GitHub Releases را برای Update بررسی کند.

- Build پایدار Prerelease را نادیده می‌گیرد؛
- Build آزمایشی می‌تواند Prerelease جدیدتر را ببیند؛
- در Windows x64، Archive رسمی و `SHA256SUMS.txt` دانلود می‌شوند؛
- قبل از جایگزینی، SHA-256 Verify می‌شود؛
- بعد از Update، TL Studio Restart می‌شود و در صورت امکان همان Project دوباره باز می‌شود.

## Release Validation

Validation مربوط به Release و Preview، بسته به Build، شامل این موارد است:

- Type-check و Build نهایی Browser TypeScript؛
- Go Test و Vet؛
- Cross-build برای Platformهای پشتیبانی‌شده؛
- Native Product Contract؛
- Custom Provider Contract؛
- Browser Smoke؛
- Agent/runtime E2E؛
- Regression Testهای Provider، Router و Plugin؛
- Windows Review Package؛
- SHA-256 Checksum برای Stable Release.

در CI از Credential واقعی User استفاده نمی‌شود.
