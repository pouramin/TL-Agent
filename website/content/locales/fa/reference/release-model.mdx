کانال‌های فعلی انتشار:

~~~text
Stable:      v0.5.0
Development: v0.6.0-alpha.1
~~~

## نسخهٔ پایدار

شاخهٔ main خط Stable Production است.

اجرای سریع نسخهٔ پایدار:

~~~bash
npx --yes tl-studio
~~~

پکیج npm یک Launcher سبک و Pin‌شده به GitHub Release متناظر است. Archive درست را برای Platform دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را داخل Project انتخاب‌شده یا فعلی اجرا می‌کند.

Workflow پایدار npm فقط Version غیرPrerelease را از main روی Dist-tag به نام latest منتشر می‌کند.

## Development Preview

شاخهٔ dev خط توسعهٔ نسخهٔ بعدی است.

Preview Build جدا از Stable Release ساخته می‌شود و برای Validation قبل از Promotion استفاده می‌شود. این Buildها npm پایدار یا GitHub Release پایدار را تغییر نمی‌دهند.

خط فعلی v0.6.0-alpha.1 شامل توسعهٔ Account Providerها و Transport بومی Gemini است.

## Portable Build

Stable Release برای این Platformها ساخته می‌شود:

- Windows x64؛
- Linux x64؛
- Linux ARM64؛
- macOS Intel x64؛
- macOS Apple Silicon ARM64.

Package شامل Executable خود TL Studio، License/Noticeها و هر Bundled Plugin نسخه‌ثابتی است که برای همان Release تنظیم شده باشد.

## Release Validation

Validation مربوط به Release و Preview، بسته به نوع Build، شامل این موارد است:

- Type-check مربوط به Browser TypeScript؛
- Build نهایی Browser؛
- Go Test و Vet؛
- Cross-build برای Platformهای پشتیبانی‌شده؛
- Native Product Contract؛
- Custom Provider Contract؛
- Browser Smoke؛
- Agent/runtime E2E؛
- Regression Testهای Provider؛
- Windows Review Package؛
- SHA-256 Checksum برای Stable Release.

در CI از Credential واقعی User استفاده نمی‌شود.
