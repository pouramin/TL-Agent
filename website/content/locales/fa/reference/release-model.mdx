title: Release و Runtime همراه
description: ساختار Releaseهای TL Agent و مدل Runtime همراه برنامه.
icon: PackageCheck
---

TL Agent، Launcher و UI خودش را همراه یک Runtime Pin‌شده منتشر می‌کند تا کاربر فقط یک Archive بگیرد و مستقیم اجرا کند.

هر Release شامل این بخش‌هاست:

- فایل اجرایی TL Agent؛
- Runtime سازگار همراه برنامه؛
- Licenseهای TL Agent؛
- Third-party Notice و Licenseهای وابستگی‌ها.

فایل `VERSION` نسخه TL Agent را مشخص می‌کند. Compatibility مربوط به Runtime جداگانه Pin می‌شود و CI آن را تست می‌کند.

Release CI برنامه را تست می‌کند، Runtime دقیق و سازگار را آماده می‌کند، TL Agent را برای سیستم‌عامل‌های پشتیبانی‌شده Build می‌کند و Archive و Checksum منتشر می‌کند.

جزئیات Low-level این Compatibility برای Maintainerها در [Runtime Integration](./runtime-integration) آمده است.
