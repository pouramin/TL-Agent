Kilo Code در حال حاضر Runtime بالادستی است که همراه TL Agent Bundle می‌شود. این صفحه برای Maintainerها و Debug سازگاری است؛ نه هویت محصول و نه Workflow عادی کاربر.

## نسخه سازگار

TL Agent نسخه Kilo را در `KILO_VERSION` Pin می‌کند و Product HTTP API همان نسخه را که Client رسمی Kilo استفاده می‌کند تست می‌کند.

## Adapter

فراخوانی‌های Browser به Runtime در یک Adapter متمرکز شده‌اند:

```text
cmd/launcher/web/kilo-api.js
```

بخش‌های UI نباید Endpointهای Runtime را مستقیم بسازند. این کار Upgrade نسخه بالادستی را قابل بررسی و تست نگه می‌دارد.

## قانون Upgrade

قبل از تغییر `KILO_VERSION`، CI باید Project Routing، Agent/Provider/Session، Messageها، Permission/Question، Eventها و یک Write Tool واقعی را با نسخه جدید تأیید کند.
