بیشتر کاربران فقط TL Agent را اجرا می‌کنند و پروژه را با Folder Picker انتخاب می‌کنند. CLI بیشتر برای Automation، Debug یا مشخص کردن پروژه از قبل است.

## `--project`

```bash
tl-agent --project /path/to/project
```

در Windows:

```powershell
tl-agent.exe --project "C:\path\to\project"
```

## `--no-browser`

اجرای TL Agent بدون باز کردن خودکار مرورگر:

```bash
tl-agent --no-browser
```

## `--listen`

مقدار پیش‌فرض `127.0.0.1` است و TL Agent عمداً فقط loopback را قبول می‌کند.

جزئیات Runtime Override عمداً از CLI Guide معمولی جدا نگه داشته شده است. Maintainerها برای تست Compatibility می‌توانند [Runtime Integration](./runtime-integration) را ببینند.
