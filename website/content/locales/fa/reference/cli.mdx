برای استفاده معمول می‌توانید TL Studio را داخل Project اجرا کنید و ادامه کار را از Workspace گرافیکی انجام دهید.

## انتخاب Project

```bash
tl-studio --project /path/to/project
```

در Windows:

```powershell
tl-studio.exe --project "C:\path\to\project"
```

Positional Project Path هم پذیرفته می‌شود:

```bash
tl-studio /path/to/project
```

## بازنشدن خودکار Browser

```bash
tl-studio --no-browser
```

Local Server همچنان Start می‌شود و آدرس `Local:` در Terminal چاپ می‌شود.

## Listen Address

```bash
tl-studio --listen 127.0.0.1
```

مقدار پیش‌فرض `127.0.0.1` است.

TL Studio عمداً Non-loopback Listen Address را Reject می‌کند.
