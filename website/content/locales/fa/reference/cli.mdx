برای استفاده معمول کافی است TL Agent را اجرا کنید و Project را با Folder Picker انتخاب کنید.

## `--project`

```bash
tl-agent --project /path/to/project
```

در Windows:

```powershell
tl-agent.exe --project "C:\path\to\project"
```

Project Path به‌صورت Positional Argument هم پذیرفته می‌شود.

## `--no-browser`

اجرای TL Agent بدون بازکردن خودکار Browser:

```bash
tl-agent --no-browser
```

## `--listen`

مقدار پیش‌فرض `127.0.0.1` است و TL Agent عمداً Non-loopback Address را قبول نمی‌کند.

## `--runtime-bin`

Override پیشرفته برای Compatibility/Test:

```bash
tl-agent --runtime-bin /path/to/runtime
```

User معمولی Release به این Option نیاز ندارد، چون Agent Engine سازگار همراه TL Agent Bundle شده است. Generic بودن Flag باعث می‌شود Product Boundary به اسم یک Vendor در CLI گره نخورد.
