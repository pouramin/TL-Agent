نسخه Stable فعلی:

```text
v0.5.0
```

نسخه Development فعلی:

```text
0.6.0-alpha.1
```

Branch `dev` در حال حاضر **5 Commit از `main` جلوتر است**. این Commitها فعلاً فقط Version/Release-readiness Metadata را تغییر داده‌اند و Behavior قابل‌استفاده Product همان Feature Set معتبر منتشرشده در v0.5.0 است.

## Branch Discipline

- `main` فقط Stable Production است؛
- `dev` خط Integration برای Development Cycle بعدی است؛
- Feature/Fix Branch از `dev` شروع می‌شود؛
- Experimental Work تا Stable Promotion آگاهانه وارد `main` نمی‌شود.

## Development Build خصوصی

Development Build از **Preview Build** در GitHub Actions استفاده می‌کند و Stable npm `latest` را تغییر نمی‌دهد.

Workflow فعلی Review ZIP مربوط به Windows x64 می‌سازد و Artifact را 14 روز نگه می‌دارد.

## Rule مربوط به Documentation

Public Site اول Stable Behavior را مستند می‌کند.

Documentation باید بین Behavior واقعاً پیاده‌سازی‌شده در `dev` و Version/Release-readiness bookkeeping تفاوت بگذارد. Capability برنامه‌ریزی‌شده تا قبل از پیاده‌سازی به‌عنوان Feature موجود معرفی نمی‌شود.
