TL Agent از یک Product Layer Local و یک Runtime بالادستی تشکیل شده است.

```text
Browser Workspace
  ↓ localhost
TL Agent UI + Go launcher
  ├─ Project Picker
  ├─ Sessions / Files / Changes
  ├─ Provider Settings UI
  ├─ Retryable Provider Recovery UI
  ├─ Local State + Appearance
  ├─ Security Boundary
  └─ Authenticated Reverse Proxy
       ↓
Bundled Kilo Runtime
       ├─ Sessions / Agents / Tools
       ├─ Provider Config + Local Auth Store
       ├─ Provider Integration / Model Execution
       └─ Project Execution
```

## مسئولیت TL Agent

- Standalone Browser Workspace؛
- Launch و مدیریت Processها؛
- Project Selection؛
- Reverse Proxy و Security Boundary؛
- Packaging، Release و Brand خود TL Agent؛
- UX مربوط به Session، File، Changes، Permission، Provider Settings، Recovery و Appearance.

## مسئولیت Runtime

Kilo در لایه زیرین مسئول Agent Execution، Toolها، جزئیات Session، Filesystem/Tool Call، ذخیره Provider Config، نگه‌داری Credentialها در Local Auth Store خودش و Model Execution است.

برای کاربر، محصول **TL Agent** است؛ Kilo یک Runtime Component زیر کاپوت باقی می‌ماند.
