TL Agent از یک Product Layer Local و یک Agent Runtime همراه برنامه تشکیل شده است.

```text
Browser Workspace
  ↓ localhost
TL Agent UI + Go launcher
  ├─ Project Picker
  ├─ Sessions / Files / Changes
  ├─ Provider Settings UI
  ├─ Retryable Provider Recovery UI
  ├─ Local State + Appearance
  ├─ Security Boundary
  └─ Authenticated Reverse Proxy
       ↓
Bundled Agent Runtime
       ├─ Sessions / Agents / Tools
       ├─ Provider Config + Local Credential Store
       ├─ Provider Integration / Model Execution
       └─ Project Execution
```

## مسئولیت TL Agent

- Standalone Browser Workspace؛
- Launch و مدیریت Processها؛
- Project Selection؛
- Reverse Proxy و Security Boundary؛
- Packaging، Release و Brand خود TL Agent؛
- UX مربوط به Session، File، Changes، Permission، Provider Settings، Recovery و Appearance.

## مسئولیت Runtime

Runtime همراه برنامه Agent Execution، Toolها، جزئیات Session، Filesystem/Tool Call، ذخیره Provider Config، نگه‌داری Credentialها و Model Execution را انجام می‌دهد.

این تفاوت یک مرز معماری است، نه هویت محصول؛ کاربر با **TL Agent** کار می‌کند و جزئیات Runtime پشت Adapter Boundary باقی می‌ماند.
