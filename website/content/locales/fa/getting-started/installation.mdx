## اجرا با یک دستور

اگر Node.js و npm نصب هستند، داخل Folder پروژه این دستور را اجرا کنید:

```bash
npx --yes tl-studio
```

پکیج npm یک Launcher سبک است که به GitHub Release پایدار متناظر متصل می‌شود. سیستم‌عامل و Architecture را تشخیص می‌دهد، Archive رسمی را دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را با Folder فعلی به‌عنوان Project اجرا می‌کند.

برای جلوگیری از بازشدن خودکار Browser:

```bash
npx --yes tl-studio --no-browser
```

## نسخهٔ Portable

Archive مناسب را از GitHub Releases بگیرید، Extract کنید و اجرا کنید:

```text
Windows:  tl-studio.exe
Linux:    ./tl-studio
macOS:    ./tl-studio
```

Build پایدار برای Windows x64، Linux x64/ARM64 و macOS Intel x64/Apple Silicon ARM64 منتشر می‌شود.

## داخل v0.6.0 چیست؟

Package عادی نسخهٔ v0.6.0 شامل Executable خود TL Studio، License/Noticeهای لازم، فایل‌های Integration تنظیم‌شده برای Release و فایل‌های Claude Web Bridge مربوط به Extension پشتیبانی‌شدهٔ Chrome است.

Graphify هنگام Add شدن به‌صورت Integration سراسری نصب می‌شود، اما دادهٔ Graph هر Project داخل `graphify-out/` همان Project باقی می‌ماند.

## بررسی فایل دانلودی

هر Release فایل `SHA256SUMS.txt` را منتشر می‌کند. برای Verify کردن Package می‌توانید Hash Archive را با مقدار منتشرشده مقایسه کنید.

Updater داخلی Windows x64 نیز قبل از جایگزینی Executable همین بررسی SHA-256 را انجام می‌دهد.

## Cache مربوط به npm Launcher

```text
Windows:     %LOCALAPPDATA%\TL-Studio\cache
Linux/macOS: ${XDG_CACHE_HOME:-~/.cache}/tl-studio
```

Launcher یک‌دستوری TL Studio را به‌عنوان System Service یا System Package نصب نمی‌کند.
