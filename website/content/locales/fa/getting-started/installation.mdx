## اجرا با یک دستور

اگر Node.js و npm نصب هستند، داخل Folder پروژه این دستور را اجرا کنید:

```bash
npx --yes tl-studio
```

پکیج npm یک Launcher سبک است که به GitHub Release پایدار متناظر Pin می‌شود. سیستم‌عامل و Architecture را تشخیص می‌دهد، Archive رسمی را دانلود می‌کند، SHA-256 را Verify می‌کند، Local Cache می‌سازد و TL Studio را با Folder فعلی به‌عنوان Project اجرا می‌کند.

برای جلوگیری از بازشدن خودکار Browser:

```bash
npx --yes tl-studio --no-browser
```

## نسخه Portable

Archive مناسب را از GitHub Releases بگیرید، Extract کنید و اجرا کنید:

```text
Windows:  tl-studio.exe
Linux:    ./tl-studio
macOS:    ./tl-studio
```

Build پایدار برای Windows x64، Linux x64/ARM64 و macOS Intel x64/Apple Silicon ARM64 منتشر می‌شود.

## داخل Package چیست؟

Release عادی v0.5 شامل Executable خود TL Studio، License/Noticeهای لازم و هر Bundled Plugin نسخه‌ثابتی است که برای همان Build Configure شده باشد.

Catalog مربوط به Bundled Plugin در v0.5.0 خالی است؛ بنابراین این Release به‌صورت پیش‌فرض Third-party Plugin همراه ندارد.

Runtime Binary محلی جداگانه‌ای هم برای نصب یا انتخاب وجود ندارد.

## بررسی فایل دانلودی

هر Release فایل زیر را منتشر می‌کند:

```text
SHA256SUMS.txt
```

برای Verify کردن Package می‌توانید Hash Archive را با مقدار منتشرشده مقایسه کنید.

## Cache مربوط به npm Launcher

Release دانلودشده جدا از Cache عادی npm نگه‌داری می‌شود:

```text
Windows:     %LOCALAPPDATA%\TL-Studio\cache
Linux/macOS: ${XDG_CACHE_HOME:-~/.cache}/tl-studio
```

Launcher یک‌دستوری TL Studio را به‌عنوان System Service یا System Package نصب نمی‌کند.
