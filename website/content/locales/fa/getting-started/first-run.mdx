## اجرای TL Studio

نسخهٔ Portable را اجرا کنید یا داخل Folder پروژه این دستور را بزنید:

~~~bash
npx --yes tl-studio
~~~

TL Studio، Local Server خودش را روی Loopback بالا می‌آورد و Browser Workspace را باز می‌کند.

## انتخاب Project

روش معمول گرافیکی است و از Folder Picker سیستم‌عامل استفاده می‌کند.

اگر npm Launcher را داخل Folder پروژه اجرا کرده باشید، همان Directory به‌صورت خودکار انتخاب می‌شود.

برای Preselect کردن Project:

~~~bash
tl-studio --project /path/to/project
~~~

در Windows:

~~~powershell
tl-studio.exe --project "C:\Users\you\Projects\my-project"
~~~

## آشنایی با Workspace

Workspace با محوریت Editor طراحی شده است:

1. از Activity Rail بین Explorer، Search، Sessions، Changes و Settings جابه‌جا شوید؛
2. Fileها را در Monaco Editor باز و Edit کنید؛
3. Agent Panel را در حالت Collapsed، Compact یا Focused استفاده کنید؛
4. Commandهای Project را در Terminal قابل Resize پایین Workspace اجرا کنید؛
5. برای File یا Project پشتیبانی‌شده Live Preview را باز کنید؛
6. Status Bar، Local Status، Changes، Agent State، Model انتخاب‌شده، Cursor و Terminal را نشان می‌دهد.

برای Command Palette از Ctrl/Cmd+K و برای Project Search از Ctrl/Cmd+Shift+F استفاده کنید.

## تنظیم Provider

وارد **Settings → Providers** شوید.

برای Provider سفارشی، Endpoint، API Type و Credential را تنظیم کنید. اگر Provider دارای Model-list API سازگار باشد، TL Studio می‌تواند Model Catalog را خودکار Discover کند.

Provider Definition و Credential جدا ذخیره می‌شوند.

## Account Login در Development

در خط توسعهٔ v0.6، کارت‌های Provider روش اتصال مناسب هر سرویس را خودکار انتخاب می‌کنند.

Account Sign-in:
- ChatGPT / Codex؛
- Claude / Claude Code برای اشتراک Claude.ai؛
- GitHub Copilot که Model Integration آن هنوز Deferred است.

API Credential:
- Claude / Anthropic؛
- Google / Gemini؛
- Hugging Face؛
- OpenRouter.

با کلیک روی کارت API-based، همان Provider Editor فعلی با Endpoint و Protocol آماده و Model Discovery خودکار باز می‌شود.

برای ChatGPT از Login رسمی OpenAI Codex استفاده می‌شود و برای اشتراک Claude.ai از Claude Code رسمی استفاده می‌شود. برنامه ابتدا CLI مربوطه را روی PATH پیدا می‌کند و در صورت نیاز می‌تواند از `npx @openai/codex` یا `npx @anthropic-ai/claude-code` استفاده کند. مسیر Executable نیز از Provider Settings قابل تنظیم است و Credential حساب Claude از تنظیمات Claude Code شخصی کاربر جدا نگه داشته می‌شود.

## اجرای Agent

Model را انتخاب کنید و Prompt بفرستید.

~~~text
Browser
→ TL Studio Session
→ Native Agent
→ Selected Provider
→ Tool Executor when needed
→ Session Persistence + Local Events
~~~

Tool نیازمند Approval در Permission UI خود TL Studio Pause می‌شود. Agent همچنین می‌تواند Interactive Question بپرسد و بعد از پاسخ شما ادامه دهد.
