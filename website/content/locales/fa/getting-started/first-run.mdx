## اجرای TL Studio

نسخهٔ Portable را اجرا کنید یا داخل Folder پروژه این دستور را بزنید:

~~~bash
npx --yes tl-studio
~~~

TL Studio، Local Server خودش را روی Loopback بالا می‌آورد و Browser Workspace را باز می‌کند.

## انتخاب Project

می‌توانید از Folder Picker سیستم‌عامل استفاده کنید یا npm Launcher را داخل Folder پروژه اجرا کنید تا همان Directory خودکار انتخاب شود.

برای Preselect کردن Project:

~~~bash
tl-studio --project /path/to/project
~~~

در Windows:

~~~powershell
tl-studio.exe --project "C:\Users\you\Projects\my-project"
~~~

## آشنایی با Workspace

محیط با محوریت Editor ساخته شده و Explorer، Search، Sessions، Changes، Settings، Monaco، Agent Panel، Terminal، Live Preview، Command Palette و Status Bar را در یک Workspace محلی کنار هم قرار می‌دهد.

برای Command Palette از Ctrl/Cmd+K و برای Project Search از Ctrl/Cmd+Shift+F استفاده کنید.

## تنظیم اتصال مدل

وارد **Settings → Providers** شوید.

نسخهٔ پایدار v0.6 علاوه بر Provider/API مستقیم، مسیرهای حسابی پشتیبانی‌شده را هم دارد:

- برای ChatGPT / Codex از Account Sign-in رسمی استفاده می‌شود؛
- برای Claude / Anthropic مسیر حساب Claude و API Key جدا از هم هستند؛
- برای Claude Web از Bridge موجود در Chrome Web Store و Session لاگین‌شدهٔ Browser استفاده می‌شود؛
- برای Google / Gemini از API Key استفاده می‌شود؛
- برای Hugging Face از API Token استفاده می‌شود؛
- برای OpenRouter از API Key استفاده می‌شود.

Provider Definition و Credential جدا از هم نگه‌داری می‌شوند.

## Model Routing اختیاری

از Model Selector می‌توانید Routerهای پشتیبانی‌شده مثل **Laya Router** یا **JEV Direct** را هم انتخاب کنید.

Profileها شامل Balanced، Lowest cost، Best quality، Fastest و حالت سخت‌گیرانهٔ Free only هستند. Router فقط بین Modelهای بومی فعال انتخاب می‌کند؛ Agent Loop، Tool، Permission، Session، Retry، Fallback، فایل‌ها و Terminal همچنان در اختیار TL Studio هستند.

## Plugin اختیاری

از **Settings → Plugins** می‌توانید Integrationهای MCP را اضافه کنید.

Graphify به‌صورت Global نصب می‌شود، اما Graph هر Project داخل `graphify-out/` همان Project باقی می‌ماند. Project جدید تا زمانی که **Build Graph** را صریح اجرا نکنید، وضعیت **Graph Missing** نشان می‌دهد.

## اجرای Agent

یک Model یا Router تنظیم‌شده را انتخاب کنید و Prompt بفرستید.

~~~text
Browser
→ TL Studio Session
→ Native Agent
→ Selected Provider / Router-selected native model
→ Tool Executor when needed
→ Session Persistence + Local Events
~~~

Tool نیازمند Approval در Permission UI خود TL Studio Pause می‌شود. Agent همچنین می‌تواند Interactive Question بپرسد و بعد از پاسخ ادامه دهد.
