## اجرای TL Agent

فایل Portable را اجرا کنید یا از Launcher یک‌دستوری استفاده کنید. TL Agent سرویس‌های محلی خودش را روی loopback بالا می‌آورد و Workspace را در مرورگر باز می‌کند.

## انتخاب پروژه

روش معمول **کاملاً محلی و گرافیکی** است: از داخل TL Agent روی انتخاب پروژه بزنید و پوشه را مستقیماً با Folder Picker سیستم‌عامل انتخاب کنید. برای این کار هیچ دستور Kilo لازم نیست.

اگر عمداً می‌خواهید پروژه را از Terminal از قبل مشخص کنید، از CLI خود TL Agent استفاده کنید:

```bash
tl-agent --project /path/to/project
```

در Windows:

```powershell
tl-agent.exe --project "C:\Users\you\Projects\my-project"
```

اگر Launcher یک‌دستوری را از داخل پوشه پروژه اجرا کنید، همان پوشه به‌صورت خودکار انتخاب می‌شود:

```bash
npx --yes github:pouramin/TL-Agent
```

## پشت صحنه چه اتفاقی می‌افتد؟

1. TL Agent پروژه و Runtime همراه برنامه را پیدا می‌کند.
2. پورت‌های آزاد روی loopback انتخاب می‌شوند.
3. یک Password تصادفی برای همان اجرا ساخته می‌شود.
4. Runtime محلی روی `127.0.0.1` اجرا می‌شود.
5. Server و Reverse Proxy محلی TL Agent بالا می‌آید.
6. Workspace در مرورگر باز می‌شود.

با بستن TL Agent، Process مربوط به Runtime هم متوقف می‌شود.
