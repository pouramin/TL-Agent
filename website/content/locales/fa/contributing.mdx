## ساختار Source

Go Launcher و Local Product Domainها زیر این مسیر هستند:

~~~text
cmd/launcher/
~~~

Browser Source با Strict TypeScript در این مسیر است:

~~~text
cmd/launcher/ui/
~~~

Generated Browser JavaScript در این مسیر ساخته می‌شود:

~~~text
cmd/launcher/web/
~~~

Public Fumadocs Documentation در این مسیر قرار دارد:

~~~text
website/
~~~

## Local Check

قبل از Product Change:

~~~bash
npm install --ignore-scripts --no-audit --no-fund
npm run check:web
npm run build:web
go test ./...
go vet ./...
~~~

برای تغییر Model Connection، Session، Question، Permission، Tool، Plugin/MCP، Browser، Provider Account یا Release، Contract/Regression Test مربوط را هم اجرا کنید.

## Ruleهای معماری

- Browser Behavior جدید باید از Product Domainهای /local/* خود TL Studio استفاده کند.
- Model Connection Definition، Discovery، Credential، Account Adapter و Direct Model Execution متعلق به TL Studio هستند.
- Session، Question، Permission و Semantic Event متعلق به TL Studio هستند.
- Built-in Tool باید Project Filesystem/Search/Process/Permission Infrastructure موجود را Reuse کند.
- Plugin/MCP Tool باید از Tool Registry و Permission Path خود TL Studio عبور کند.
- Secret داخل JSON Config معمولی یا Browser Storage نرود.
- Monaco فقط Editor Engine است، نه Filesystem Authority.
- Project Code در Preview روی Loopback Origin جدا باقی بماند.
- Editor Asset از CDN Load نشود.

## Rule مربوط به Provider Account

Provider Account Integration فقط باید از روش عمومی و مستند Third-party استفاده کند.

OAuth و API Credential Material در سمت Go و Credential Vault باقی می‌مانند.

Credential دستی API و Credential حساب از هم جدا هستند.

Account Integration نباید Native Agent یا Tool Execution Model خود TL Studio را جایگزین کند.

## Rule مربوط به Release و Documentation

رفتار موجود در main را می‌توان به‌عنوان Stable مستند کرد.

رفتار dev فقط با برچسب روشن Development Preview قابل انتشار در مستندات است.

Capability منتشرنشده نباید بخشی از مسیر Stable npm یا GitHub Release معرفی شود.

Wording تاریخی پیاده‌سازی در Documentation فعلی Product نگه‌داری نمی‌شود.
