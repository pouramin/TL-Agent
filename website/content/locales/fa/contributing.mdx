## Source Layout

Go Launcher و Native Local Product Domainها زیر این مسیر هستند:

```text
cmd/launcher/
```

Browser Source با Strict TypeScript:

```text
cmd/launcher/ui/
```

Generated Browser JavaScript:

```text
cmd/launcher/web/
```

Generated JavaScript را Source اصلی تغییر Product در نظر نگیرید.

Public Fumadocs Documentation:

```text
website/
```

## Local Check

قبل از Product Change:

```bash
npm install --ignore-scripts --no-audit --no-fund
npm run check:web
npm run build:web
go test ./...
go vet ./...
```

برای تغییر Model Connection، Session، Question، Permission، Tool، Plugin/MCP، Browser یا Release، Contract/Regression Test مربوط را هم اجرا کنید.

## Native Architecture Rule

- Browser Behavior جدید باید از Product Domainهای `/local/*` خود TL Studio استفاده کند.
- Model Connection Definition، Model Discovery، Credential و Direct Model Execution متعلق به TL Studio هستند.
- Session، Question، Permission و Semantic Event متعلق به TL Studio هستند.
- Built-in Tool باید Project Filesystem/Search/Process/Permission Infrastructure موجود را Reuse کند.
- Plugin/MCP Tool باید از Tool Registry و Permission Path خود TL Studio عبور کند.
- Secret داخل JSON Config معمولی یا Browser Storage نرود.
- Monaco فقط Editor Engine است، نه Filesystem Authority.
- Project Code در Preview روی Loopback Origin جدا از Privileged Control Server بماند.
- Editor Asset از CDN Load نشود.

## Rule مربوط به Plugin/MCP

Contract فعلی MCP روی stdio است.

Save کردن Plugin نباید Arbitrary Local Code را Start کند. Enable باید Explicit و Confirm‌شده باقی بماند.

Project/Global Scope، Working Directory Confinement، Credential Reference، Tool Discovery و Process Cleanup باید Trust Boundary فعلی را حفظ کنند.

Bundled Plugin باید Version-pinned و در Release Manifest تعریف شده باشد و Executable مخفیانه وارد Package نشود.

## Rule مربوط به Account Connection

Generic Account Adapter Domain بخشی از Product Boundary خود TL Studio است. Public Documentation فقط Behavior موجود در Stable `main` را توضیح می‌دهد.

## Release Rule

Branch `main` تنها Source of Truth برای Public Stable Documentation است. Stable npm Publish و Release Packaging از Source معتبر Stable ساخته می‌شوند.

Release/CI Gate معماری فعلی TL Studio را Enforce و Production Packaging را Validate می‌کند.

## Documentation Rule

Stable Source روی Branch `main` تنها Source of Truth برای Documentation عمومی است.

Public Language روی **TL Studio** متمرکز بماند و فقط Behavior موجود در Stable Source مستند شود.

Architecture Wording منسوخ فقط به‌خاطر History حفظ نشود.
