TL Agent یک **Local Workspace مستقل برای Coding Agentها** است. از داخل مرورگر می‌توانید با Projectهای Local، Sessionها، Agentها، Modelها، Toolها، Providerها، File Attachmentها، Permissionها و File Changes کار کنید؛ بدون اینکه مجبور باشید داخل IDE بمانید.

## هویت محصول

محصولی که نصب و استفاده می‌کنید **TL Agent** است. Project Selection، Sessionها، Provider Settings، Attachmentها، Recovery، Security، Packaging و Browser Experience همگی بخشی از خود TL Agent هستند.

```text
User
 ↓
TL Agent
 ├─ Browser Workspace
 ├─ Project Picker
 ├─ Sessions / Files / Changes
 ├─ Attachments + Provider Settings
 ├─ Local Security
 └─ Launcher + Packaging
      ↓
Bundled Agent Runtime
      ↓
Models / Providers / Project Tools
```

Runtime همراه برنامه یک لایه اجرایی داخلی است. در استفاده روزمره با یک محصول کار می‌کنید: **TL Agent**.

## چه کارهایی می‌توانید انجام دهید؟

- انتخاب Folder پروژه با Folder Picker سیستم‌عامل؛
- ساخت، Rename و حذف Session؛
- انتخاب Agent و Model؛
- Attach کردن Image، PDF و فایل‌های Text/Code با File Picker، Drag & Drop یا Paste از Clipboard؛
- اضافه‌کردن Custom Providerهای سازگار با OpenAI Compatible، OpenAI Responses یا Anthropic Messages از داخل Settings؛
- ارسال Prompt و مشاهده Live Activity مربوط به Agent و Toolها؛
- Resume کردن Retryable Provider Error بدون از دست رفتن File Changes قبلی؛
- تأیید یا رد Permissionها و پاسخ به Questionهای Agent؛
- مشاهده Project Files و Changes هر Session؛
- Stop یا Abort کردن Run فعال؛
- تغییر Theme و Font Size رابط؛
- استفاده بدون VS Code، JetBrains، Cursor، Docker یا Cloud Backend متعلق به TL Agent.

## نسخه Stable فعلی

**v0.2.0 اولین baseline پایدار TL Agent است.** مسیر پیش‌فرض npm روی Stable Channel قرار دارد:

```bash
npx --yes tl-agent
```

Buildهای آزمایشی می‌توانند روی Channelهای Prerelease مثل `tl-agent@alpha` ادامه پیدا کنند، بدون اینکه مسیر Stable تغییر کند.
