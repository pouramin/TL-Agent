TL Studio یک **Browser IDE و Coding-Agent Workspace با معماری Local-first** است. در Stable v0.5، Workspace، Monaco Editor، Search، Terminal، Preview، Session، Question، Permission، Provider، Plugins/MCP و Native Agent همگی پشت Contractهای Local خود TL Studio اجرا می‌شوند.

## معماری محصول

```text
User
 ↓
Browser Workspace
 ↓
TL Studio Local Core
 ├─ Files / Search / Terminal / Preview
 ├─ Provider Registry + Discovery + Credential Vault
 ├─ Sessions / Questions / Permissions / Events
 ├─ Tool Registry + Native Tool Executor
 ├─ Plugins / MCP
 └─ Native Agent
       ↓
   Selected Provider
```

اگر Protocol یا Capability انتخاب‌شده توسط Native Model Client پشتیبانی نشود، Error به‌صورت شفاف برمی‌گردد.

## قابلیت‌های v0.5

- Workspace دسکتاپ با محوریت Editor، شامل Activity Rail، Context Sidebar، Monaco، Agent Panel، Terminal، Floating Preview و Status Bar؛
- Command Palette با `Ctrl/Cmd+K`؛
- Panelهای قابل Resize و Persist به‌همراه حالت‌های Collapsed، Compact و Focused برای Agent؛
- Project File قابل‌نوشتن با Revision/Conflict Protection و External-change Reconciliation؛
- Project Search و Process Execution در Scope پروژه؛
- Preview مبتنی بر Capability برای Web، Document، Image، Audio و Video؛
- Session Lifecycle و Semantic Persistence کاملاً Native؛
- Interactive Question و Permission Policy کاملاً Native؛
- Direct Provider Execution برای OpenAI-compatible Chat Completions، OpenAI Responses و Anthropic Messages؛
- Model Discovery برای Provider با Catalog قابل Search و Cache Fallback؛
- Credential Vault محلی؛
- Native Model/Tool/Model Agent Loop؛
- Core Coding Toolها به‌همراه Toolهای Dynamic از MCP Plugin؛
- تنظیم MCP از نوع stdio در Scope پروژه یا Global با Enable/Test صریح؛
- Integration اختیاری JEV/OpenRouter روی همان Native Provider Path.

## نسخه Stable

نسخه Stable فعلی:

```text
v0.5.0
```

اجرای سریع:

```bash
npx --yes tl-studio
```

نسخه Portable هم از GitHub Releases قابل دریافت است.
