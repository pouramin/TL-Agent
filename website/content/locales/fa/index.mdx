TL Studio یک **محیط کدنویسی Local-first با Agent بومی** است. Workspace، Sessionها، Toolها، Permissionها، Providerها، Credentialها، Terminal، Preview و Plugins/MCP همگی پشت Contractهای محلی خود TL Studio قرار دارند.

این سایت رفتار Stable و Development Preview را از هم جدا نگه می‌دارد:

~~~text
Stable:      v0.5.0
Development: v0.6.0-alpha.1
~~~

## معماری محصول

~~~text
User
 ↓
Browser Workspace
 ↓
TL Studio Local Core
 ├─ Files / Search / Terminal / Preview
 ├─ Provider Registry + Discovery + Credential Vault
 ├─ Sessions / Questions / Permissions / Events
 ├─ Tool Registry + Native Tool Executor
 ├─ Plugins / MCP
 └─ Native Agent
       ↓
   Selected Provider
~~~

اگر Protocol یا Capability پشتیبانی نشود، خطای Unsupported Capability به‌صورت شفاف برمی‌گردد.

## نسخهٔ پایدار v0.5

نسخهٔ پایدار شامل این موارد است:

- Workspace دسکتاپ با محوریت Editor و شامل Monaco، Explorer، Search، Sessionها، Changes، Terminal، Preview و Command Palette؛
- Session، Question، Permission، Event معنایی و Persistence محلی؛
- اجرای مستقیم مدل از طریق Adapterهای متعلق به TL Studio برای OpenAI-compatible، OpenAI Responses و Anthropic؛
- Model Discovery، Catalog قابل Search و Cache محلی؛
- Credential Vault خود TL Studio؛
- Agent Loop بومی مدل/Tool/مدل؛
- Toolهای داخلی کدنویسی و Toolهای سازگار MCP؛
- توزیع پایدار با npm و Portable Release.

## پیش‌نمایش توسعهٔ v0.6

خط توسعهٔ فعلی این قابلیت‌ها را اضافه می‌کند:

- Transport بومی Google Gemini generateContent؛
- Slot جدا برای Credential دستی API و Credential حساب؛
- اتصال حساب ChatGPT/Codex از مسیر رسمی OpenAI Codex و یک Provider Bridge ایزوله؛
- ورود اشتراک Claude.ai از مسیر رسمی Claude Code، در کنار مسیر مستقل **Claude / Anthropic API Key**؛
- Preset مبتنی بر API Key برای **Google / Gemini**، **Hugging Face** و **OpenRouter**؛
- Model Discovery خودکار از همان Provider Registry؛
- جایگاه Account Login برای GitHub Copilot که Model Integration آن هنوز Deferred است.

Bridgeهای حساب ChatGPT و Claude جای Native Agent اصلی TL Studio را نمی‌گیرند؛ Tool، Permission، Session، Persistence، تغییرات پروژه و ادامهٔ مدل → Tool → مدل همچنان در اختیار خود TL Studio هستند. اعتبارسنجی واقعی حساب Claude هنوز یکی از Gateهای Development Preview است.

## شروع سریع

اجرای نسخهٔ پایدار:

~~~bash
npx --yes tl-studio
~~~

نسخهٔ Portable نیز از GitHub Releases قابل دریافت است.
