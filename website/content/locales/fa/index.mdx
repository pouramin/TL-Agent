TL Agent یک **Local Workspace مستقل برای Coding Agentها** است. از داخل مرورگر می‌توانید با پروژه‌های Local، Sessionها، Agentها، Modelها، Toolها، Permissionها و Changes فایل کار کنید؛ بدون اینکه مجبور باشید داخل یک IDE بمانید.

## هویت محصول

محصولی که نصب و استفاده می‌کنید **TL Agent** است. Kilo Code در لایه زیرین نقش Agent Runtime را دارد و اجرای Agent، Toolها، Sessionها و اتصال به Providerها را انجام می‌دهد.

```text
User
 ↓
TL Agent
 ├─ Browser Workspace
 ├─ Project Picker
 ├─ Sessions + Changes
 ├─ Local Security
 └─ Launcher + Packaging
      ↓
Agent Runtime (Kilo)
      ↓
Models / Providers / Project Tools
```

این جداسازی عمدی است: در استفاده روزمره با **TL Agent** کار می‌کنید؛ Kilo یک Runtime زیرساختی است، نه هویت اصلی محصول.

## چه کارهایی می‌توانید انجام دهید؟

- انتخاب پوشه پروژه با Folder Picker سیستم‌عامل؛
- ساخت، Rename و حذف Session؛
- انتخاب Agent و Model؛
- ارسال Prompt و مشاهده Live Activity مربوط به Agent و Toolها؛
- تأیید یا رد Permissionها؛
- پاسخ به سؤال‌های تعاملی Agent؛
- مشاهده فایل‌های پروژه و Changes؛
- Stop یا Abort کردن اجرای فعال؛
- استفاده بدون VS Code، JetBrains، Cursor، Docker یا بک‌اند ابری TL Agent.

## از کجا شروع کنم؟

ابتدا [نصب](./getting-started/installation) و بعد [اولین اجرا](./getting-started/first-run) را ببینید.
