TL Studio یک محیط توسعهٔ مستقل و محلی است که هستهٔ آن **TL Studio Native Agent** است.

کانال‌های فعلی:

~~~text
Stable:      v0.6.0
Development: v0.7.0-alpha.1
~~~

## نسخهٔ پایدار v0.6.0

نسخهٔ پایدار فعلی این قابلیت‌ها را دارد:

- چرخهٔ Agent، Tool Executor، Session، Question، Permission، Terminal، Preview و Persistence متعلق به خود TL Studio؛
- Protocolهای مستقیم برای OpenAI-compatible Chat Completions، OpenAI Responses، Anthropic Messages و Google Gemini `generateContent`؛
- اتصال حساب ChatGPT/Codex و حساب Claude از مسیر Clientهای رسمی Providerها؛
- پشتیبانی از Claude Web Bridge از طریق Chrome Web Store، بدون خارج‌کردن Session احرازهویت‌شده از Browser؛
- Routerهای Laya و JEV Direct با Profileهای Balanced، Lowest cost، Best quality، Fastest و حالت سخت‌گیرانهٔ Free only؛
- Graphify به‌صورت Integration سراسری، با Graph مخصوص هر Project داخل `graphify-out/`؛
- کارت‌های Responsive برای Pluginها و حفظ پشتیبانی از MCP سفارشی Project-scoped؛
- بررسی Update از بخش About و Verify کردن SHA-256 قبل از جایگزینی نسخه در Windows x64.

Router فقط Model بومی مناسب را انتخاب می‌کند. Tool، فایل‌ها، Permission، Session، Retry، Fallback، Terminal و ادامهٔ مدل → Tool → مدل همچنان در اختیار خود TL Studio هستند.

## شروع سریع

نسخهٔ پایدار را داخل Project اجرا کنید:

~~~bash
npx --yes tl-studio
~~~

نسخهٔ Portable هم از GitHub Releases قابل دریافت است.
