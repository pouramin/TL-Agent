## مرورگر خودکار باز نشد

ممکن است Server محلی همچنان در حال اجرا باشد. آدرس `Local:` را از Terminal کپی و دستی باز کنید. اگر `--no-browser` داده‌اید، این رفتار طبیعی است.

## Folder Picker پوشه را قبول نمی‌کند

یک Directory موجود انتخاب کنید. TL Agent مسیر محلی را قبل از تغییر پروژه Normalize و Validate می‌کند.

## Runtime پیدا نمی‌شود

Release رسمی TL Agent Runtime سازگار را همراه خودش دارد. این خطا بیشتر هنگام اجرای Source یا Override دستی Runtime دیده می‌شود.

## Model یا Provider دیده نمی‌شود

وضعیت Model/Provider از Runtime و حساب Provider می‌آید. Login لازم را کامل و Provider State را Refresh کنید.

## Agent منتظر مانده

داخل TL Agent دنبال Permission Request یا Question باز بگردید.

## گزارش Bug

سیستم‌عامل، نسخه TL Agent، نسخه Runtime، مراحل بازتولید و Error غیرحساس را بفرستید. API Key یا Token را منتشر نکنید.
